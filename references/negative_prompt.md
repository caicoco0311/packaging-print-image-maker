# Negative prompt blocks

The headings and single fenced blocks below are a machine-readable contract. Keep exactly one `common` block and one block for each role from `role_1` through `role_6`.

## common

```text
seller brand, seller logo, watermark, QR code, phone number, email address, URL, certification badge, regulatory seal, unsupported claim, medical claim, misspelled "Your Logo", missing "Your Logo" on a clearly visible main package face, off-center package logo, logo outside the package, warped lettering, cropped lettering, random words, lorem ipsum, duplicated package parts, inconsistent package geometry, impossible opening, incorrect material, distorted perspective, low resolution, blur, noise, plastic-looking paper, CGI artifacts
```

## role_1

```text
flat catalog snapshot, repetitive centered lineup, more than two hero packages, cluttered props, seller identity, weak focal point
```

## role_2

```text
missing "customized Solution", misspelled "customized Solution", duplicate title, title outside the top clean space, title overlapping product, more than six complete labels or packages, tiny unreadable label wall, seller catalog screenshot
```

## role_3

```text
not a four-panel grid, fewer than four panels, more than four panels, repeated identical close-up, missing material detail, substituted user-requested material, generic material replacing the requested material, decorative collage without production detail
```

## role_4

```text
empty packaging with no plausible use, wrong product inside or beneath the packaging, floating object, impossible adhesion, impossible scale, generic studio duplicate of the hero
```

## role_5

```text
more than six complete print items, dense miniature label mosaic, illegible technical specification sheet, impossible dieline, seller artwork, contact information, certification mark
```

## role_6

```text
fewer than three meaningful views, mixed product identities, inconsistent dimensions, inconsistent colors, inconsistent closure, inconsistent print placement, impossible back or interior structure
```
