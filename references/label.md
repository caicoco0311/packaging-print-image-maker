# Label positive prompt blocks

## common

```text
Treat the label as the requested package component and preserve its shape, substrate, print zone, finish, and placement on the corresponding container.
```

## role_2

```text
Present 3–6 complete large labels as sheets, rolls, or production-ready pieces with visible printing and die-cut edges.
```

## role_4

```text
Apply the label naturally to the correct real product container.
```

## role_5

```text
Show complete label faces, a restrained production layout, print surface, and die-cut contour.
```

## role_6

```text
Include label face, material or edge view, and label-on-container view while preserving one design.
```
