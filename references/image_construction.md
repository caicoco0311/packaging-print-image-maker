# Positive image prompt blocks

`build_prompts.py` reads exactly one non-empty `text` block for `common` and each role. Keep positive visual instructions here; keep prohibited content in `negative_prompt.md`.

## common

```text
Create one independent square premium ecommerce packaging image with photorealistic materials, plausible construction, controlled commercial light, grounded shadows, crisp useful detail, and no border. Preserve the approved product identity while varying placement, camera, scale, and negative space across the set.
```

## role_1

```text
Create the commercial hero with one or two primary packages, restrained relevant props, a strong focal point, and an identity-appropriate asymmetrical, overhead, side, or 45-degree advertising composition.
```

## role_2

```text
Create the category showcase with 3–6 complete large packages or print items. Reserve a clean deliberate title zone above the products and keep all products below it.
```

## role_3

```text
Create a strict four-panel close-up grid with four different angles or magnifications. Always devote at least one panel to recognizable material appearance and surface texture. Follow an injected user material lock exactly when present. Use the other panels for print, finish, embossing, foil, die-cut, thickness, coating, fold, corner, seam, edge, or closure details.
```

## role_4

```text
Create a believable product-specific usage photograph with physically plausible interaction and a camera distance and viewpoint distinct from the hero.
```

## role_5

```text
Create a readable print-artwork and production-layout image with 3–6 complete large print items or surfaces at useful scale.
```

## role_6

```text
Combine at least three meaningful views of the same package—front, side, top, back, open, or interior—with identical geometry, material, color, closure, finish, and print placement.
```
