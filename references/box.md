# Box positive prompt blocks

## common

```text
Preserve box length, width, height, board material, opening method, internal structure, and print-panel locations.
```

## role_2

```text
Show useful front, side, top, open, and interior information and communicate length × width × height visually.
```

## role_4

```text
Place the corresponding product inside the box in a plausible open, retail, gift, or transport state.
```

## role_5

```text
Show box-panel artwork, an unfolded print layout, or a clear print zone without presenting an impossible net.
```

## role_6

```text
Include at least three consistent views, with an open or interior view when relevant.
```
