# Sticker positive prompt blocks

## common

```text
Treat stickers as standalone decals or sticker sheets rather than structural container labels.
```

## role_2

```text
Present 3–6 complete large stickers on a sheet or as individual die-cut pieces with clean peel edges.
```

## role_4

```text
Apply the sticker realistically to an appropriate object or package with correct adhesion and surface perspective.
```

## role_5

```text
Show complete sticker faces, sheet spacing, print surface, kiss-cut or die-cut contour, and backing paper.
```

## role_6

```text
Include face, edge or peeled corner, backing, and applied views while preserving one design system.
```
