# 印刷包装电商图生成 Skill

面向印刷包装商品的 AI 组图工作流，支持文字、商品参考图、商品链接及 Excel/CSV/TSV 批量输入。

## 功能

- Excel 批量提交多个商品需求，按行独立处理。
- 按标签、贴纸、包装盒及其他包装类型加载对应 Markdown 规则。
- 检索并筛选 Alibaba.com 高销量参考商品，支持参考结果缓存。
- 生成商品标题、关键词及六张 950 × 950 PNG 商品展示图。
- 通过产品身份约束、物理一致性检查、文字修复和输出校验组织交付。

## 使用条件

这是由 AI Agent 执行的 Skill，不是独立运行的网页应用。请将完整文件夹安装到兼容 Agent 的技能目录，并按照 SKILL.md 使用。需要可用的图片生成、网页检索及相应脚本运行环境；部分脚本使用额外的 Python 或 JavaScript 库。

原始 Skill 当前检索规则以 Alibaba.com 为准；其他平台支持请以实际实现为准。参考素材用于需求分析和生成引导，不应直接复制他人的图片、品牌、文案或受保护设计。生成结果应在使用前核对实物与展示信息。

## 实践背景

针对家庭经营的阿里巴巴国际站店铺，减少商品发布中找图、修图与重复编写提示词的操作。据使用者反馈，应用工作流后，单人每日发品量由个位数提升至约 30 个；该数据为店铺实践反馈，非独立基准测试。
